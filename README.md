# Clepsydra

Помодоро-таймер в меню-баре macOS. 25 минут работы, 5 минут перерыва,
полноэкранная цитата между ними.

## Установка

Готовой сборки пока нет, приложение собирается из исходников. Нужны Mac на
Apple Silicon с macOS 14 и Command Line Tools (`xcode-select --install`);
полный Xcode не требуется.

```bash
git clone https://github.com/ilya-pesterev/clepsydra.git
cd clepsydra
./build.sh
cp -R Clepsydra.app /Applications/ && open /Applications/Clepsydra.app
```

Иконка песочных часов появится в меню-баре — ни в Dock, ни в переключателе
задач приложения нет. Автозапуск включается там же в меню: «Запускать при
входе».

## Как это работает

Иконка песочных часов в меню-баре, в меню — «Запустить сессию». Дальше рядом с
иконкой тикает отсчёт.

Когда 25 минут кончились, звучит сигнал и на всех мониторах разворачивается
тёмный экран с мыслью Сунь-Цзы, Марка Аврелия, Сенеки, Эпиктета, Лао-цзы или
Монтеня — и одной кнопкой «Отдохнуть». Экран поверх всего, включая чужой
полноэкранный режим, и не закрывается ни Esc, ни Cmd+W, ни Enter: выход —
клик по кнопке или запасная комбинация **⌘⇧0**, подсказка к которой написана
прямо на экране.

Нажали — экран остаётся, но кнопка уступает место отсчёту: `04:12`, `04:11`.
Встали, налили кофе, посмотрели в окно. Хотите вернуться к работе раньше —
**⌘⇧0** убирает экран, а перерыв продолжает идти и досчитывает в меню-баре,
где к этому времени появилась чашка.

Когда перерыв кончился, экран возвращается с другой цитатой и двумя кнопками:
«Начать» — следующий помидор, «Хватит» — выйти из круга.

Идущий помидор или перерыв отменяется пунктом «Сбросить». Паузы нет
(см. [ADR-0003](docs/adr/0003-no-pause.md)).

## Иконка

`Resources/Clepsydra.icns` собирается из мастера `Resources/icon-source.png` —
квадрат 1024 с прозрачностью, предмет внутри занимает 824 точки, как тело
системных иконок:

```bash
./Tools/make-icns.sh
```

Каждый размер пересчитывается из мастера, а не давится из соседнего: в `.icns`
они и так лежат отдельными картинками.

Если исходник пришёл с ровным фоном, его снимает

```bash
swift Tools/trim-background.swift вход.jpg Resources/icon-source.png
```

Заливка от краёв, а не Vision: она не трогает однотонные участки внутри
предмета и возвращает полупрозрачным пикселям кромки их цвет — иначе по краю
остаётся серая бахрома.

## Появление экрана

Окно чернеет за 0,3 секунды, содержимое въезжает уже по черноте — иначе
движение было бы видно сквозь полупрозрачный экран поверх рабочего стола.

Движение разное в двух режимах. Наклейку **шлёпают**: фигура и плашки приходят
крупнее нужного, с перекрученным наклоном, и садятся с перелётом; строки по
очереди через 70 мс. Цитату философа **проявляют**: портрет, текст и автор
всплывают снизу без масштаба и перелёта. Кнопка в обоих случаях приходит
последней и без движения — по едущей кнопке легко промахнуться.

Системная настройка «Уменьшить движение» оставляет одно проявление.

## Портреты философов

Философский режим показывает портрет автора цитаты, если файл найден: чёрно-белый
и приглушённый, без канта и тени — противоположность наклейке.

Кладите PNG в `Resources/philosophers/`, имя файла — латиницей по автору:

| Автор | Файл | Цитат |
|---|---|---|
| Сунь-Цзы | `sun-tzu.png` | 10 |
| Марк Аврелий | `marcus-aurelius.png` | 10 |
| Сенека | `seneca.png` | 10 |
| Эпиктет | `epictetus.png` | 8 |
| Лао-цзы | `lao-tzu.png` | 8 |
| Монтень | `montaigne.png` | 4 |

Сопоставление живёт в `Quotes.portraits`; тест следит, чтобы у каждого автора
был файл и чтобы лишних записей не завелось. Файла нет — цитата покажется одна
на чёрном, как раньше.

## Режим Стетхема

Переключатель в меню меняет содержимое экрана: вместо Сенеки и Марка Аврелия —
пацанские цитаты наклейками, каждая строка своей плашкой. Собрано так же, как
философский экран: фигура сверху, текст под ней, кнопка внизу — одной колонкой
по оси. Круг, длительности, кнопки, отсчёт и ⌘⇧0 остаются теми же.

Имени на экране нет: реплики никому не приписаны, название режима живёт в меню.

Фотографий в репозитории нет — это снимки реального человека, права на них не
наши. Положите свои PNG в `Resources/statham/`, и `build.sh` заберёт их в бандл.
Без файлов режим работает и показывает наклейки без фигуры.

Фон нужен **прозрачный**: белый кант считается из альфа-канала, иначе получится
прямоугольник с каймой. Снять фон пакетом:

```bash
swift Tools/remove-background.swift Resources/statham/*.png
```

Скрипт работает через Vision — тот же механизм, что у «Удалить фон» в
Просмотре, — и перезаписывает файлы, обрезая их по контуру фигуры. Оригиналы
стоит отложить заранее: `Resources/statham-originals/` в `.gitignore` как раз
для этого.

Если Mac уснул и срок вышел без вас, интервал молча отменяется — показывать
«пора отдохнуть» через час после закрытия крышки нелепо
(см. [ADR-0002](docs/adr/0002-overdue-interval-is-cancelled.md)).

## Сборка

```bash
./build.sh
```

Пересобирает `Clepsydra.app` — чистый arm64, подписанный ad-hoc. Перед сборкой
прогоняются тесты.

## Тесты

```bash
swift run ClepsydraTests
```

Проверяют автомат состояний: переходы по времени, сброс, «Хватит», пробуждение
из сна, отсчёт и список цитат.

Прогон — обычная программа, а не `swift test`: XCTest и swift-testing
поставляются только с полным Xcode, а собираться всё должно на одних Command
Line Tools. Тесты запускаются и внутри `./build.sh` перед сборкой бандла.

## Раздача другим людям

Ad-hoc подпись Gatekeeper отклоняет — у друга приложение при первом запуске
заблокируется. Чтобы этого не было, нужен Apple Developer Program, сертификат
Developer ID Application и нотаризация.

Один раз сохраняем учётные данные в связку ключей:

```bash
xcrun notarytool store-credentials "clepsydra" --apple-id "you@example.com" --team-id "AB12CD34EF" --password "abcd-efgh-ijkl-mnop"
```

`--password` — не пароль от Apple ID, а app-specific password с appleid.apple.com.

Дальше каждая релизная сборка — одной командой:

```bash
./build.sh --release
```

Скрипт подпишет с hardened runtime и timestamp, отправит на нотаризацию,
дождётся вердикта, прикрепит тикет к бандлу и соберёт `Clepsydra.zip`.

## Стек

SwiftPM + AppKit (`NSStatusItem`, `NSMenu`, `NSWindow`) + SwiftUI внутри
полноэкранного экрана. `LSUIElement`, минимум macOS 14.

Автомат состояний вынесен в отдельную библиотеку `ClepsydraCore` — без AppKit,
без таймеров и без обращений к системным часам: момент всегда приходит снаружи
параметром. Поэтому он покрыт тестами целиком.
