# 1. Экран закрывается только кликом, клавиатура не работает

Дата: 2026-09-02

## Статус

Принято

## Контекст

Экран между помидорами существует ровно затем, чтобы вырвать человека из
контекста работы. Если его можно закрыть тем же движением, каким закрывают
любой другой диалог, он превращается в мигание, которое проматывают не читая.

Обычное для macOS поведение — Esc, Cmd+W и Enter на кнопке по умолчанию — здесь
работает против замысла: пальцы уже на клавиатуре, и Enter отбивается рефлексом
раньше, чем глаз доходит до цитаты.

Противоположная крайность — окно, из которого нельзя выйти вообще, — приложение,
которое сносят после первого важного звонка.

## Решение

Окно уровня `.screenSaver`, поверх чужого полноэкранного режима, на всех
мониторах, забирает фокус. `keyDown`, `cancelOperation` и `performKeyEquivalent`
проглатываются целиком: ни Esc, ни Cmd+W, ни Enter, ни пробел ничего не делают.

Выход — только клик по кнопке. Cmd+Tab и переключение Spaces остаются рабочими:
их обрабатывает система, а не приложение.

## Последствия

- Из любого состояния экрана выход есть и всегда в один клик: после помидора —
  «Отдохнуть», после перерыва — «Начать» или «Хватит».
- Пока экран висит, приложение нельзя закрыть с клавиатуры: меню-бар под окном
  недостижим, а Cmd+Q проглочен. Это осознанная цена; путь наружу в один клик
  делает её приемлемой.
- Без мыши или трекпада кнопку не нажать: она отвечает только на клик.

## Обновление от 2026-09-02: запасной выход ⌘⇧0

Решение выше проверку реальностью не прошло. В первой же установленной сборке
экран показался **без кнопки**: `NSHostingView` в роли `contentView` подогнал
окно под свой контент — 2304×2165 при экране 2304×1296 со сдвигом вниз, — и
кнопка уехала за нижнюю кромку. Клавиатура проглочена, меню-бар под окном
недостижим; пришлось перезагружать Mac.

Сама причина исправлена: SwiftUI больше не управляет размером окна. Но урок в
другом — экран, единственный выход из которого может отказать, обязан иметь
запасной, не зависящий от вёрстки.

Добавлена комбинация **⌘⇧0**: закрывает экран из любой фазы и возвращает в
простой. Подсказка написана прямо на экране, мелким и приглушённым.

Замысел это не ломает: ⌘⇧0 требует трёх пальцев и осознанного намерения — её не
отобьёшь рефлексом, как Enter. Esc, Cmd+W, Enter и пробел по-прежнему не делают
ничего.
