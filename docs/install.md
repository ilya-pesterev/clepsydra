# Установка

Терминал не нужен ни разу.

1. Скачайте файл `Clepsydra-<версия>.dmg`.
2. Откройте файл двойным щелчком — появится окно с иконкой Clepsydra и ярлыком
   с подписью «Applications».
3. Перетащите иконку на ярлык. Приложение скопируется в папку «Программы».
4. Извлеките том Clepsydra и запустите приложение из Launchpad.

Иконка песочных часов появится в меню-баре. Окна у приложения нет: всё
управление — в меню под иконкой.

## Первый запуск

Собранная из репозитория Clepsydra подписана ad-hoc: без сертификата Apple
Developer ID и без нотаризации. Такое приложение macOS при первом запуске
остановит. Это проходимо — вот весь путь.

Если DMG выпущен релизной сборкой, с сертификатом и нотаризацией, весь этот
раздел можно пропустить: приложение откроется двойным щелчком и ни о чём не
спросит.

**Первый двойной щелчок.** macOS покажет окно с заголовком

> Файл «Clepsydra» не был открыт

и объяснением: Apple не удалось подтвердить, что файл не содержит вредоносного
ПО. Так и есть — подтверждать нечем, у сборки нет нотаризации.

Кнопок две, и **синяя по умолчанию — «Переместить в Корзину»**. Не нажимайте
Enter не глядя: приложение уедет в Корзину. Нажмите вторую, **«Готово»**.
Приложение не запустится, и это нормально — это ещё не отказ, а первый шаг.

**Разрешение.** Откройте  → «Системные настройки…» → «Конфиденциальность и
безопасность». Прокрутите до раздела «Безопасность»: там будет строка

> Файл «Clepsydra» заблокирован для защиты Вашего Mac.

Рядом кнопка **«Все равно открыть»**. Нажмите её и подтвердите Touch ID или
паролем.

**Второй запуск.** macOS переспросит в последний раз — нажмите «Открыть».
Дальше приложение запускается как обычное, и больше ни о чём не спрашивает.

Разрешение выдаётся приложению в том месте, куда вы его положили. Если потом
перенести Clepsydra в другую папку, macOS спросит снова.

## Чего быть не должно

Сообщение

> Приложение «Clepsydra» повреждено, и его не удается открыть.

— это другое. Оно значит, что подпись бандла сломалась по дороге, и обходного
пути у него нет: «Все равно открыть» в настройках не появится. Так бывает,
если приложение доставали из архива утилитой, которая не сохраняет расширенные
атрибуты. Скачайте DMG заново и перетаскивайте из него — `Tools/make-dmg.sh`
кладёт бандл в образ через `ditto`, и подпись переживает дорогу целиком.

## Обновления

Дальше приложение следит за новыми версиями само — молча, раз в сутки. Окон и
значков не появляется: когда выйдет новая версия, пункт «Проверить обновления»
в меню под иконкой сменится на «Обновить до 1.1».

Щелчок по нему скачивает новую версию, заменяет ею установленную и запускает
уже новую. Иконка возвращается в меню-бар через несколько секунд. Ни образа, ни
перетаскивания, ни «Все равно открыть» второй раз: путь из этого руководства
проходят один раз.

Если что-то не вышло — щелчок откроет страницу релиза в браузере, и оттуда
приложение ставится руками, как в первый раз.

## Запуск при входе

В меню под иконкой есть «Запускать при входе». Галочка переживает
перезагрузку: приложение регистрируется как login item через `SMAppService`,
а не прописывается в старый список автозапуска.

Включать её стоит после того, как приложение переехало в «Программы»:
регистрация запоминает путь, и запуск при входе сломается, если потом
приложение переложить.

## Названия

Формулировки записаны по macOS 26 на русском языке. В более ранних версиях
слова в окнах немного другие, но путь тот же: сначала окно с отказом, потом
«Конфиденциальность и безопасность» и кнопка рядом со строкой про
заблокированный файл.

Если macOS у вас на английском, искать надо это:

| По-русски | По-английски |
|---|---|
| Файл «Clepsydra» не был открыт | “Clepsydra” Not Opened |
| Готово | Done |
| Переместить в Корзину | Move to Trash |
| Конфиденциальность и безопасность | Privacy & Security |
| Все равно открыть | Open Anyway |
