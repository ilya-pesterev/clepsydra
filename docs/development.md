# Разработка Clepsydra

Подробности, которым не место в README: как устроен круг, откуда берутся
картинки, чем собирается бандл и что нужно, чтобы раздать сборку другим.

## Как это работает

Иконка песочных часов в меню-баре, в меню — «Запустить сессию». Дальше рядом с
иконкой тикает отсчёт.

Когда 25 минут кончились, звучит сигнал и на всех мониторах разворачивается
тёмный экран с мыслью Сунь-Цзы, Марка Аврелия, Сенеки, Эпиктета, Лао-цзы или
Монтеня — и одной кнопкой «Отдохнуть». Экран поверх всего, включая чужой
полноэкранный режим, и не закрывается ни Esc, ни Cmd+W, ни Enter: выход —
клик по кнопке или запасная комбинация **⌘⇧0**, подсказка к которой написана
прямо на экране.

Нажали — экран остаётся, но кнопка уступает место отсчёту: `04:12`, `04:11`.
Встали, налили кофе, посмотрели в окно. Хотите вернуться к работе раньше —
**⌘⇧0** убирает экран, а перерыв продолжает идти и досчитывает в меню-баре,
где к этому времени появилась чашка.

Когда перерыв кончился, экран возвращается с другой цитатой и двумя кнопками:
«Начать» — следующий помидор, «Хватит» — выйти из круга.

Идущий помидор или перерыв отменяется пунктом «Сбросить». Паузы нет
(см. [ADR-0003](adr/0003-no-pause.md)).

## Режим Стетхема

Переключатель в меню меняет содержимое экрана: вместо Сенеки и Марка Аврелия —
пацанские цитаты наклейками, каждая строка своей плашкой. Собрано так же, как
философский экран: фигура сверху, текст под ней, кнопка внизу — одной колонкой
по оси. Круг, длительности, кнопки, отсчёт и ⌘⇧0 остаются теми же.

Имени на экране нет: реплики никому не приписаны, название режима живёт в меню.

Фотографий в репозитории нет — это снимки реального человека, права на них не
наши. Положите свои PNG в `Resources/statham/`, и `build.sh` заберёт их в бандл.
Без файлов режим работает и показывает наклейки без фигуры.

Фон нужен **прозрачный**: белый кант считается из альфа-канала, иначе получится
прямоугольник с каймой. Снять фон пакетом:

```bash
swift Tools/remove-background.swift Resources/statham/*.png
```

Скрипт работает через Vision — тот же механизм, что у «Удалить фон» в
Просмотре, — и перезаписывает файлы, обрезая их по контуру фигуры. Оригиналы
стоит отложить заранее: `Resources/statham-originals/` в `.gitignore` как раз
для этого.

Если Mac уснул и срок вышел без вас, интервал молча отменяется — показывать
«пора отдохнуть» через час после закрытия крышки нелепо
(см. [ADR-0002](adr/0002-overdue-interval-is-cancelled.md)).

## Портреты философов

Философский режим показывает портрет автора цитаты, если файл найден: чёрно-белый
и приглушённый, без канта и тени — противоположность наклейке.

Кладите PNG в `Resources/philosophers/`, имя файла — латиницей по автору:

| Автор | Файл | Цитат |
|---|---|---|
| Сунь-Цзы | `sun-tzu.png` | 10 |
| Марк Аврелий | `marcus-aurelius.png` | 10 |
| Сенека | `seneca.png` | 10 |
| Эпиктет | `epictetus.png` | 8 |
| Лао-цзы | `lao-tzu.png` | 8 |
| Монтень | `montaigne.png` | 4 |

Сопоставление живёт в `Quotes.portraits`; тест следит, чтобы у каждого автора
был файл и чтобы лишних записей не завелось. Файла нет — цитата покажется одна
на чёрном, как раньше.

## Появление экрана

Окно чернеет за 0,3 секунды, содержимое въезжает уже по черноте — иначе
движение было бы видно сквозь полупрозрачный экран поверх рабочего стола.

Движение разное в двух режимах. Наклейку **шлёпают**: фигура и плашки приходят
крупнее нужного, с перекрученным наклоном, и садятся с перелётом; строки по
очереди через 70 мс. Цитату философа **проявляют**: портрет, текст и автор
всплывают снизу без масштаба и перелёта. Кнопка в обоих случаях приходит
последней и без движения — по едущей кнопке легко промахнуться.

Системная настройка «Уменьшить движение» оставляет одно проявление.

## Иконка

`Resources/Clepsydra.icns` собирается из мастера `Resources/icon-source.png` —
квадрат 1024 с прозрачностью, предмет внутри занимает 824 точки, как тело
системных иконок:

```bash
./Tools/make-icns.sh
```

Каждый размер пересчитывается из мастера, а не давится из соседнего: в `.icns`
они и так лежат отдельными картинками.

Если исходник пришёл с ровным фоном, его снимает

```bash
swift Tools/trim-background.swift вход.jpg Resources/icon-source.png
```

Заливка от краёв, а не Vision: она не трогает однотонные участки внутри
предмета и возвращает полупрозрачным пикселям кромки их цвет — иначе по краю
остаётся серая бахрома.

## Сборка

```bash
./build.sh
```

Пересобирает `Clepsydra.app` — чистый arm64, подписанный ad-hoc. Перед сборкой
прогоняются тесты.

## Номер сборки

Номер сборки — момент сборки по UTC в виде `20260904153012`: он растёт сам,
читается как дата, и `build.sh` подставляет его в `CFBundleVersion` бандла
через `Tools/build-number.sh`. В `Resources/Info.plist` вместо номера ноль:
константа в репозитории у двух разных сборок одинаковая, а править её руками —
ровно тот шаг, который забывают.

Человеческая версия `CFBundleShortVersionString` остаётся `1.0` и от номера не
зависит; «О программе» показывает обе — «Версия 1.0 (20260904153012)».

## Тесты

```bash
swift run ClepsydraTests
```

Проверяют автомат состояний: переходы по времени, сброс, «Хватит», пробуждение
из сна, отсчёт и список цитат.

Заодно — скрипты сборки и выпуска: номер сборки читается как дата и со
временем растёт, имя DMG и тег релиза берут версию из `Info.plist`, ворота
релиза не пускают невыросший номер, а в описании релиза есть требования и
абзац про первый запуск. Скрипты проверяются снаружи, запуском, — ровно так,
как их зовут `build.sh` и `release.sh`.

Прогон — обычная программа, а не `swift test`: XCTest и swift-testing
поставляются только с полным Xcode, а собираться всё должно на одних Command
Line Tools. Тесты запускаются и внутри `./build.sh` перед сборкой бандла.

## DMG

```bash
./build.sh --dmg
```

Кладёт рядом с бандлом `Clepsydra-<версия>.dmg`: версия в имени — человеческая,
`CFBundleShortVersionString` из `Resources/Info.plist`, и берётся оттуда
скриптом `Tools/dmg-name.sh`, а не пишется в сборке руками.

Внутри — оформленное окно: слева иконка Clepsydra, справа ярлык Applications,
между ними стрелка и подпись «Перетащи в папку». Панель инструментов и боковая
панель скрыты, размер окна и позиции иконок заданы. Образ только для чтения и
сжат (UDZO).

Собирает `Tools/make-dmg.sh`. Фон рисует `Tools/make-dmg-background.swift` —
сразу в двух разрешениях, @1x и @2x, которые `tiffutil` складывает в один TIFF:
на retina Finder берёт из него нужное, и картинка не мылит. Размеры окна и
координаты иконок заданы в `Tools/make-dmg.sh` и оттуда уходят и в AppleScript,
и в рисовальщик аргументами: правится одно место, стрелка с иконками не
расходится.

Оформление ставит Finder по AppleScript, поэтому при первом прогоне macOS
спросит разрешение на автоматизацию, а на машине без графического сеанса
сборка DMG не пройдёт (см. [ADR-0008](adr/0008-dmg-window-is-dressed-by-finder.md)).

Обычный `./build.sh` DMG не делает: монтировать том и ждать Finder на каждой
сборке для разработки незачем.

Что человек увидит при первом запуске скачанного DMG — в [docs/install.md](install.md).

## Релиз

```bash
./release.sh 1.0
```

Одна команда: прогон тестов, сборка бандла и DMG, тег `v1.0` в `origin` и
черновик релиза на GitHub с образом и его суммой sha256.

Релиз уходит в `origin` — `ilya-pesterev/clepsydra`, туда же, куда код. Задачи
живут в другом репозитории, и релизы там ни при чём. Адрес скрипт берёт из
`git remote get-url origin` и печатает первой строкой: посмотрите на неё.

**Версию называет человек**, и она сверяется с `CFBundleShortVersionString`
из `Resources/Info.plist` до всего остального. Релиз `v1.0` с бандлом версии
0.9 не создаётся: страница обещала бы не то, что покажет «О программе».
Поднимать версию — отдельный коммит перед выпуском.

**Что изменилось** пишется руками в `docs/releases/<версия>.md` и уходит в
описание релиза первым разделом. Файла нет — выпуска нет, и узнаётся это до
сборки, а не после. Требования и абзац про первый запуск дописывает
`Tools/release-notes.sh`: они от релиза к релизу не меняются, а забыть их
на странице проще всего.

**До публикации скрипт отказывается**, если:

- названная версия разошлась с бандлом (`Tools/release-tag.sh`);
- тег уже есть локально, в `origin` или как релиз на GitHub;
- в рабочем дереве есть незакоммиченные изменения — тег указал бы не на то,
  что выпускается;
- ветка не отправлена в `origin` — тег указал бы на коммит, которого там нет;
- номер сборки не больше номера прошлого релиза (`Tools/release-gate.sh`,
  те же ворота, что у `./build.sh --release`);
- тесты не прошли — их прогоняет `build.sh` перед сборкой бандла.

**Что попало в бандл, скрипт говорит вслух.** Портретов и фотографий в
репозитории нет, сборка берёт их с машины автора; если какая-то папка пустая,
скрипт называет, какой экран уйдёт без картинок, и ждёт подтверждения.
`--yes` подтверждает заранее.

**Релиз создаётся черновиком.** Пока он в черновике, файл уже можно скачать и
пройти установку целиком — это и есть проверка. Открыть людям — отдельный
явный шаг:

```bash
gh release edit v1.0 --repo ilya-pesterev/clepsydra --draft=false
```

Собранный образ подписан ad-hoc: Gatekeeper при первом запуске остановит, и
описание релиза честно рассказывает, как пройти этот путь. Нотаризованную
сборку делает `./build.sh --release --dmg` — см. [Раздача другим
людям](#раздача-другим-людям); `release.sh` её не выпускает.

После удачного выпуска номер релиза записывается в `last-release-build` —
файл нужно закоммитить.

Артефакт пока один, DMG. Когда появится архив для обновления, он встаёт в
список `artifacts` в `collect_artifacts`: сумму ему посчитает тот же цикл.
Новый шаг выпуска — ещё одна строка в списке шагов внизу `release.sh`.

## Раздача другим людям

Ad-hoc подпись Gatekeeper отклоняет — у друга приложение при первом запуске
заблокируется. Чтобы этого не было, нужен Apple Developer Program, сертификат
Developer ID Application и нотаризация.

Один раз сохраняем учётные данные в связку ключей:

```bash
xcrun notarytool store-credentials "clepsydra" --apple-id "you@example.com" --team-id "AB12CD34EF" --password "abcd-efgh-ijkl-mnop"
```

`--password` — не пароль от Apple ID, а app-specific password с appleid.apple.com.

Дальше каждая релизная сборка — одной командой:

```bash
./build.sh --release
```

Скрипт подпишет с hardened runtime и timestamp, отправит на нотаризацию,
дождётся вердикта, прикрепит тикет к бандлу и соберёт `Clepsydra.zip`.

Ключи складываются: `./build.sh --release --dmg` соберёт ещё и DMG, подпишет
его тем же сертификатом, нотаризует отдельно и проверит через `spctl`.
Gatekeeper смотрит на скачанный файл, а не только на приложение внутри него:
нотаризованный бандл в неподписанном образе даёт человеку ровно то окно, ради
которого весь релиз и затевался.

Если нотаризация образа не прошла, бандл к этому моменту уже нотаризован —
раздавать можно `Clepsydra.zip`, пока образ не починен.

Выпуск останавливается, если номер сборки не больше номера прошлого релиза:
последний выпущенный номер лежит в `last-release-build`, `--release` сверяется
с ним до сборки и переписывает после удачной раздачи — файл нужно закоммитить.
Ворота одни на двоих, `Tools/release-gate.sh`: `./release.sh` сверяется с тем
же файлом и пишет в него тот же номер.
Не выросший номер значит, что часы на машине сбились: обновление такой релиз
никому не покажет.

## Стек

SwiftPM + AppKit (`NSStatusItem`, `NSMenu`, `NSWindow`) + SwiftUI внутри
полноэкранного экрана. `LSUIElement`, минимум macOS 14.

Автомат состояний вынесен в отдельную библиотеку `ClepsydraCore` — без AppKit,
без таймеров и без обращений к системным часам: момент всегда приходит снаружи
параметром. Поэтому он покрыт тестами целиком.
